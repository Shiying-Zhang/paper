# Paper Reading Notes

个人论文阅读笔记归档，主要涵盖计算机视觉 / AI 领域。

## 在线访问

https://Shiying-Zhang.github.io/paper

## 项目说明

- 基于 Jekyll 构建静态网站，部署在 GitHub Pages
- 网站源码在 `gh-pages` 分支
- 支持按关键词搜索、标签筛选、年份/评分排序
- 每篇论文包含：标题、作者、会议/期刊、评分、标签、笔记正文、论文/代码链接

## 如何添加新论文笔记

切换到 `gh-pages` 分支，在 `_papers/` 目录下新建一个 `.md` 文件，填写 front matter 和笔记正文即可。详见 `gh-pages` 分支的 README。
